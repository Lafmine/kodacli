features

Что умеет koda

Не автодополнение, а напарник, который понимает контекст всего проекта и доводит задачу до готового diff'а.

--context

Видит весь проект

Читает структуру и нужные файлы рабочего проекта, чтобы учитывать связи между модулями.

--agent

Действует сам

Разбивает задачу на шаги, редактирует несколько файлов и прогоняет тесты, пока не получится.

--diff

Ничего лишнего

Запись файлов и команды требуют подтверждения в default-режиме. Есть read-only plan и доверенный bypass.

--shell

Живёт в терминале

Запускает PowerShell-команды в текущем workspace с таймаутом и ограничением вывода.

--any-editor

Не спорит с редактором

Работает рядом с VS Code, Cursor, JetBrains или любым другим редактором — без плагинов.

--local

Бережёт контекст

Сохраняет историю сессий локально и позволяет продолжить разговор после перезапуска.

faq

Коротко о главном

Это заменяет мой редактор?

Нет. Koda работает рядом — в Windows PowerShell, пока ты пишешь код в привычном IDE.

Куда уходит код?

Модель получает историю запроса и результаты явно вызванных инструментов. Секреты хранятся локально.

Можно откатить правку?

Используй git для отката. В default-режиме Koda спрашивает разрешение перед записью файлов и shell-командами.

Что нужно для запуска?

Windows 10 или 11, PowerShell, Git и Node.js версии 20 или новее.
