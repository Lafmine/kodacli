Вы приглашены в Koda Code

Koda Code запускается прямо в Windows PowerShell, помогает работать с проектом, менять файлы и держать контекст задачи в терминале.

На главную
1
Открой Windows PowerShell.
2
Вставь команду установки и дождись завершения.
3
Перейди в папку проекта и запусти koda.
